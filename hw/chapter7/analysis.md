# 第七章：CPU 调度实验

## Q1：三个长度均为 200 的任务

### 理论计算
所有任务在时间 0 到达，不计上下文切换开销。

FIFO 按 A、B、C 顺序执行：
- A：开始时间 0，完成时间 200。
- B：开始时间 200，完成时间 400。
- C：开始时间 400，完成时间 600。

平均响应时间 = (0 + 200 + 400) / 3 = 200。
平均周转时间 = (200 + 400 + 600) / 3 = 400。

三个任务长度相同，SJF 的平均响应时间和平均周转时间与 FIFO 相同。

### 实验验证
FIFO 和 SJF 的实测平均响应时间均为 200.00，
平均周转时间均为 400.00，与理论计算一致。

原始输出：
- [FIFO](data/q1_fifo.txt)
- [SJF](data/q1_sjf.txt)

## Q2：任务长度为 100、200、300

### 理论计算
所有任务在时间 0 到达，不计上下文切换开销。
输入顺序为 A=100、B=200、C=300。

FIFO 的执行顺序：
- A：开始时间 0，完成时间 100。
- B：开始时间 100，完成时间 300。
- C：开始时间 300，完成时间 600。

各任务响应时间分别为 0、100、300。
平均响应时间 = (0 + 100 + 300) / 3 ≈ 133.33。

各任务周转时间分别为 100、300、600。
平均周转时间 = (100 + 300 + 600) / 3 ≈ 333.33。

输入顺序已经按照任务长度从小到大排列，
所以 SJF 与 FIFO 的执行顺序和结果相同。

### 实验验证
FIFO 和 SJF 的实测平均响应时间均为 133.33，
平均周转时间均为 333.33，与理论计算一致。

原因是输入任务已经按长度从小到大排列，SJF 无需改变执行顺序，
因此这组任务不能体现 SJF 相比 FIFO 的优势。

原始输出：
- [FIFO](data/q2_fifo.txt)
- [SJF](data/q2_sjf.txt)

## Q3：RR 调度，时间片为 1

### 理论计算
所有任务在时间 0 到达，不计上下文切换开销。
分别对前两题的任务使用 RR，时间片设为 1。

RR 按 A、B、C 的顺序轮流执行，每次最多运行 1 个时间单位。
三个任务首次运行的时间分别为 0、1、2，
所以两组任务的平均响应时间都是 (0 + 1 + 2) / 3 = 1。

#### 第一组：200、200、200
前 199 轮结束时，时间为 597，每个任务还剩 1。
A、B、C 分别在 598、599、600 完成。

平均周转时间 = (598 + 599 + 600) / 3 = 599。

#### 第二组：100、200、300
前 99 轮结束时，时间为 297。
A 再运行 1 个时间单位，在 298 完成。
此后 B 和 C 继续轮流执行，B 在 499 完成。
最后 C 独自运行，在 600 完成。

平均周转时间 = (298 + 499 + 600) / 3 ≈ 465.67。

### 实验验证
第一组实测平均响应时间为 1.00，平均周转时间为 599.00。
第二组实测平均响应时间为 1.00，平均周转时间为 465.67。
两组结果均与理论计算一致。

原始输出：
- [RR：200、200、200](data/q3_rr_equal.txt)
- [RR：100、200、300](data/q3_rr_mixed.txt)

### 对比分析
对于这两组任务，RR 的平均响应时间均降至 1，
因为每个任务很快就能获得第一次运行机会。

但平均周转时间分别增至 599 和约 465.67，
高于前两题 FIFO/SJF 的 400 和约 333.33。
这是因为任务交替执行，推迟了前面任务的完成时间。

## Q4：SJF 和 FIFO 何时具有相同的周转时间？

### 理论分析
在所有任务同时到达、不计上下文切换开销的条件下，
如果 FIFO 队列已经按任务长度从小到大排列，
它的执行顺序就与 SJF 相同，因此周转时间相同。
所有任务长度都相等，是这种情况的一个特例。

Q1 的 200、200、200 和 Q2 的 100、200、300 都符合这一条件。

### 对照实验预测
将输入顺序改为 A=300、B=200、C=100。

FIFO 按 A、B、C 执行：
- A 在 300 完成。
- B 在 500 完成。
- C 在 600 完成。
平均周转时间 = (300 + 500 + 600) / 3 ≈ 466.67。

SJF 按 C、B、A 执行：
- C 在 100 完成。
- B 在 300 完成。
- A 在 600 完成。
平均周转时间 = (100 + 300 + 600) / 3 ≈ 333.33。

预计这组任务使用 SJF 的平均周转时间更短，
因为短任务不必等待长任务先完成。

### 实验验证
逆序任务的 FIFO 实测平均周转时间为 466.67，
SJF 实测平均周转时间为 333.33，与预测一致。

结合 Q1、Q2 可知：FIFO 的任务顺序已经按长度从小到大排列时，
两种算法的周转时间相同；存在长任务排在短任务前面时，
SJF 可以通过调整顺序降低平均周转时间。。

原始输出：
- [FIFO：逆序任务](data/q4_fifo_reverse.txt)
- [SJF：逆序任务](data/q4_sjf_reverse.txt)

## Q5：SJF 和 RR 何时具有相同的响应时间？

### 理论分析
假设所有任务在时间 0 到达，不计上下文切换开销。

一个充分条件是：
1. RR 的初始队列已经按任务长度从小到大排列。
2. 时间片大于或等于最长任务的长度。

此时每个任务都能在第一次获得 CPU 时运行至完成，
RR 的执行顺序与 SJF 相同，因此各任务的响应时间相同。

所有任务长度相等且时间片不小于该长度，也是符合条件的情况。
仅仅增大时间片还不够：如果 RR 队列不是按长度排序，
其执行顺序仍可能与 SJF 不同。

### 实验预测
使用任务 A=100、B=200、C=300，RR 时间片设为 300。

SJF 和 RR 都按 A、B、C 顺序执行：
- A 首次运行时间为 0。
- B 首次运行时间为 100。
- C 首次运行时间为 300。

平均响应时间 = (0 + 100 + 300) / 3 ≈ 133.33。

补充：上述时间片条件是充分条件，并非必要条件。
对于这组已排序任务，时间片为 200 也能得到相同响应时间，
因为 A、B 都在首次运行时完成，C 仍然在时间 300 首次运行。
C 后续是否被划分为多个时间片，不影响它的首次响应时间。

### 实验验证
时间片为 300 和 200 时，RR 各任务的实测响应时间均为
0.00、100.00、300.00，平均响应时间均为 133.33，
与 Q2 的 SJF 结果一致，验证了理论预测。

原始输出：
- [SJF 基准：Q2](data/q2_sjf.txt)
- [RR：时间片 300](data/q5_rr_q300.txt)
- [RR：时间片 200](data/q5_rr_q200.txt)

## Q6：任务长度增加对 SJF 响应时间的影响

### 理论分析
假设所有任务同时在时间 0 到达，不计上下文切换开销。

SJF 中，一个任务的响应时间等于排在它之前的任务长度之和。
因此，将所有任务长度同时扩大 k 倍，响应时间也扩大 k 倍，
平均响应时间同样扩大 k 倍。

最先执行的任务响应时间始终为 0。
如果只增加最后一个任务的长度，则不会改变任何任务的首次运行时间，
因此平均响应时间不变。

### 实验预测
使用三组任务，每组任务数相同，长度按比例增加：

| 任务长度 | 各任务响应时间 | 平均响应时间 |
|---|---|---|
| 10、20、30 | 0、10、30 | 13.33 |
| 100、200、300 | 0、100、300 | 133.33 |
| 1000、2000、3000 | 0、1000、3000 | 1333.33 |

预计任务长度每扩大 10 倍，平均响应时间也扩大 10 倍。
表中数值保留两位小数。

### 实验验证
三组任务的实测平均响应时间分别为 13.33、133.33、1333.33。
结果与预测一致：所有任务长度按相同比例增大时，
SJF 的平均响应时间也按相同比例增大（输出存在小数舍入）。

原因是后面的任务必须等待前面的任务完整执行结束，
而前面任务的运行时间也随之按比例增加。

原始输出：
- [SJF：10、20、30](data/q6_sjf_small.txt)
- [SJF：100、200、300，复用 Q2](data/q2_sjf.txt)
- [SJF：1000、2000、3000](data/q6_sjf_large.txt)

## Q7：RR 时间片对响应时间的影响及最坏情况公式

### 理论分析
假设 N 个任务都在时间 0 到达，按固定队列顺序运行，
时间片为 q，不计上下文切换开销。

最后一个任务首次运行前，最多需要等待前面 N-1 个任务，
每个任务最多运行一个时间片 q。

因此，最坏情况下的首次响应时间为：
R_max = (N - 1) × q。

当排在前面的任务长度都不小于 q 时，达到这个上界。
若某些任务不足一个时间片就完成，实际等待时间会更短。

当所有任务长度都不小于 q 时，各任务响应时间为：
0、q、2q、……、(N-1)q。

平均响应时间为：
R_avg = (N - 1) × q / 2。

对于固定工作负载，增大时间片会使响应时间不减。
当前面的任务都能在首个时间片内完成后，
继续增大时间片不再改变首次响应时间，RR 表现为 FIFO。

### 实验预测
固定三个任务长度为 100、100、100，改变时间片：

| 时间片 q | 各任务响应时间 | 平均响应时间 | 最大响应时间 |
|---|---|---|---|
| 1 | 0、1、2 | 1 | 2 |
| 10 | 0、10、20 | 10 | 20 |
| 50 | 0、50、100 | 50 | 100 |
| 100 | 0、100、200 | 100 | 200 |
| 200 | 0、100、200 | 100 | 200 |

当 q 不超过 100 时，最大响应时间为 (3-1)q = 2q。
当 q=200 时，每个任务只需要 100 就能完成，
所以实际最大响应时间为 200，小于上界 400。

### 实验验证
时间片为 1、10、50、100、200 时，实测平均响应时间分别为
1.00、10.00、50.00、100.00、100.00；
最大响应时间分别为 2.00、20.00、100.00、200.00、200.00。

结果与预测一致。在任务足够长时，响应时间随时间片线性增加；
当时间片已经足够让任务一次执行完毕时，响应时间不再增加。
实验也验证了最坏响应时间上界 (N-1)q。

原始输出：
- [RR：q=1](data/q7_rr_q1.txt)
- [RR：q=10](data/q7_rr_q10.txt)
- [RR：q=50](data/q7_rr_q50.txt)
- [RR：q=100](data/q7_rr_q100.txt)
- [RR：q=200](data/q7_rr_q200.txt)
